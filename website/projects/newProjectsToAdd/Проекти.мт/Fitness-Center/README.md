# Fitness Center

**Fitness Center** е настолно приложение за управление на фитнес програми, хранителни режими и потребителски профили. Проектът е разработен с **C# Windows Forms** и използва **SQL Server LocalDB** база данни.

## Описание

Приложението позволява на потребителите да създават профил, да влизат в системата, да заявяват фитнес програми според избрани мускулни групи и да генерират хранителен план според въведени лични данни и цел. Администраторите могат да управляват потребители, хранителни продукти и фитнес програми.

## Основни функционалности

### За потребители

- Регистрация и вход в системата.
- Преглед на профилна информация.
- Генериране на фитнес програма по избрани мускулни групи:
  - гърди;
  - гръб;
  - бицепс;
  - трицепс;
  - крака;
  - корем.
- Генериране на хранителен режим според:
  - години;
  - височина;
  - тегло;
  - пол;
  - цел: сваляне, поддържане или качване на килограми.
- Запазване на хранителен план към текущия потребител.
- Преглед на създадени фитнес и хранителни планове.

### За администратори

- Управление на потребители:
  - добавяне;
  - редактиране;
  - изтриване;
  - задаване на роля.
- Управление на хранителни продукти:
  - добавяне;
  - редактиране;
  - изтриване;
  - преглед на калории, протеини, въглехидрати и мазнини.
- Управление на фитнес програми:
  - преглед на потребителски заявки;
  - одобряване на програми;
  - изтриване на програми.

## Инсталация и стартиране

### 1. Необходими програми

Инсталирайте:

- **Visual Studio** с workload **.NET desktop development**;
- **.NET Framework 4.7.2 Developer Pack**;
- **SQL Server Express LocalDB**.

### 2. Отваряне на проекта

Отворете solution файла във Visual Studio:

```text
Fitness Center/Fitness Center.sln
```

### 3. Възстановяване на NuGet пакетите

Ако Visual Studio не възстанови пакетите автоматично, използвайте:

```powershell
nuget restore "Fitness Center.sln"
```

или от Visual Studio:

```text
Build > Restore NuGet Packages
```

### 4. Проверка на базата данни

Приложението използва следния connection string в `App.config`:

```xml
<add name="FitnessCenterDb"
     connectionString="Data Source=(LocalDB)\MSSQLLocalDB;AttachDbFilename=|DataDirectory|\FitnessCenter.mdf;Integrated Security=True;Connect Timeout=30;Encrypt=False"
     providerName="System.Data.SqlClient" />
```

Файлът на базата данни трябва да бъде достъпен като:

```text
bin/Debug/FitnessCenter.mdf
```

а log файлът като:

```text
bin/Debug/FitnessCenter_log.ldf
```

Ако стартирате проекта от чисто копие, уверете се, че `.mdf` и `.ldf` файловете са налични в output директорията или променете `AttachDbFilename` към правилния път.

### 5. Стартиране

Стартирайте проекта чрез:

```text
F5
```

или:

```text
Debug > Start Debugging
```

Началната форма е `LoginForm`.

## База данни

Проектът работи с LocalDB база `FitnessCenter.mdf`. По кода се използват следните основни таблици:

| Таблица | Предназначение |
|---|---|
| `Users` | Съхранява потребители, пароли, имейли и роли. |
| `Exercises` | Съдържа упражнения, серии, повторения и мускулна група. |
| `UserExercises` | Съхранява заявени/създадени фитнес програми за потребители. |
| `FoodItems` | Съдържа хранителни продукти и хранителни стойности. |
| `WeeklyDietPlans` | Съхранява хранителни планове към потребители. |
| `DietPlanFoodItems` | Свързва хранителен план с конкретни продукти. |

## Потребителски роли

В приложението се използва колоната `IsAdmin` от таблицата `Users`.

Поддържани стойности:

```text
Admin
User
```

- `Admin` отваря административния панел.
- `User` отваря потребителския панел.

Новите регистрации се създават автоматично с роля `User`.

## Бележки за разработка

- Проектът съдържа Windows Forms интерфейс и е предназначен за стартиране под Windows.
- `Program.cs` стартира приложението с `LoginForm`.
- Основната комуникация с базата е в `Data/DatabaseAccess.cs` и директно във form класовете.
- Папките `bin/`, `obj/` и `.vs/` са build/IDE артефакти и обикновено не се качват в GitHub.
- В `.gitignore` са игнорирани `.mdf` и `.ldf` файлове. Ако базата трябва да бъде споделена с проекта, добавете SQL script за създаване на схемата или предоставете базата отделно.
- В текущия код паролите се записват като обикновен текст. За реална употреба е препоръчително да се използва password hashing.
- Част от класовете в `Logic/` и `Models/` са празни и могат да бъдат използвани за по-добро разделяне на бизнес логиката от UI формите.
